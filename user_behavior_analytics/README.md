# Анализ логов пользовательской активности и поведения клиентов 📊

Этот проект посвящен разведочному анализу данных (EDA) логов активности пользователей и профилей клиентов с использованием библиотек **Pandas**, **Matplotlib** и **Seaborn**. 

В ходе работы были сопоставлены действия пользователей с их демографическими характеристиками, определены самые популярные платформы и выявлены особенности поведения клиентов с премиум-статусом.

## 📋 Задачи проекта
1. Загрузить, объединить и провести первичный анализ двух датасетов (размеры, типы данных, пропущенные значения, описательная статистика).
2. Выявить уникальных клиентов с наибольшим числом успешных операций.
3. Определить наиболее эффективную и популярную платформу для успешных действий.
4. Проанализировать предпочтения клиентов с премиум-статусом.
5. Визуализировать распределение возраста клиентов в зависимости от их типа.
6. Построить график распределения числа успешных операций.
7. Изучить зависимость успешных операций от возраста пользователей на платформе `computer`.

## 💾 Описание данных

Проект оперирует двумя источниками данных (CSV-файлы):

### 1. `3_user_data.csv` (Данные о пользователях)
* `client` – идентификатор пользователя.
* `premium` – наличие премиум-подписки (`True` / `False`).
* `age` – возраст клиента.

### 2. `3_logs.csv` (Логи активности)
* `client` – идентификатор пользователя.
* `success` – результат операции (`True` — успех, `False` — неуспех).
* `platform` – используемая платформа (`phone`, `computer`, `tablet`).
* `time` – время совершения операции (в формате Unix).

## 🛠 Используемый стек технологий
* **Python 3**
* **Pandas** — предобработка, фильтрация и агрегация данных.
* **Matplotlib** — базовая визуализация и кастомизация графиков.
* **Seaborn** — построение продвинутых статистических графиков (гистограммы, countplot, графики плотности распределения).

## 🚀 Основные результаты и инсайты (Key Findings)

* **Уникальные платформы:** Всего пользователи совершают операции с **3** платформ: `phone`, `computer` и `tablet`.
* **Аномальная активность (Крупные клиенты):** Была выявлена группа из 9 клиентов, совершивших аномально высокое количество успешных действий — ровно по **41 операции** каждый (в то время как абсолютное большинство клиентов совершили всего от 1 до 3 операций). 
  * *Список ID лидеров:* `12179, 28719, 36165, 52870, 61468, 61473, 78349, 82563, 92584`.
* **Доминирование мобильных устройств:** 
  * Самой успешной платформой в целом оказался **Phone** (2019 успешных операций).
  * Премиум-клиенты также отдают абсолютное предпочтение мобильным телефонам (**Phone** — 246 операций).
* **Распределение возраста:** При анализе плотности распределения возраста было замечено, что среди обычных клиентов есть явный пик активности в районе 28 лет, в то время как распределение премиум-клиентов более равномерное с небольшим ростом в старшей возрастной группе (после 50 лет).
* **Специфика десктопной платформы (`computer`):** При детальном анализе успешных операций на ПК с помощью `sns.countplot` было обнаружено, что наибольшее количество конверсий совершают пользователи в возрасте **28 лет**.

## 📊 Примеры визуализации

В проекте построены:
1. `sns.displot(kde=True)` — для сравнения плотности распределения возраста обычных и премиум-пользователей.
2. `sns.barplot` — для отображения распределения общего числа успешных операций по клиентам.
3. `sns.countplot` — для выявления точного возраста-лидера по транзакциям на компьютерах.
